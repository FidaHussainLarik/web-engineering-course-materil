What is Semantic HTML?

Semantic HTML means using HTML tags that clearly describe the meaning and purpose of their content.

For example, instead of using a generic div for everything, we can use header, nav, main, article, section, aside, and footer.

<header>

Definition: The <header> element represents introductory content for a webpage or a section.

Why do we use it? We use <header> to contain introductory information such as a website title, logo, heading, or introduction.

Easy way to remember: Header = Introduction / Beginning

Example:

<header>
    <h1>My Website</h1>
    <p>Welcome to my website!</p>
</header>

<nav>

Definition: The <nav> element represents a section containing important navigation links.

Why do we use it? We use <nav> to help users move between important pages or sections of a website.

Easy way to remember: Nav = Navigation / Where can I go?

Example:

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="contact.html">Contact</a>
</nav>

<main>

Definition: The <main> element contains the main or most important content of the webpage.

Why do we use it? We use <main> to tell the browser and other tools which content is the primary content of the page.

Easy way to remember: Main = The most important content

Example:

<main>
    <h1>My Courses</h1>
    <p>These are the courses I am studying.</p>
</main>

Important: A webpage normally has one main element representing its primary content.

<section>

Definition: The <section> element represents a major thematic group of content.

Why do we use it? We use <section> to divide a webpage into meaningful topics or areas.

Easy way to remember: Section = One topic / One group of content

Example:

<section>
    <h2>My Education</h2>
    <p>I am studying Computer Science.</p>
</section>

A webpage might have sections such as About Me, Education, Skills, Projects, and Contact.

<article>

Definition: The <article> element represents a self-contained piece of content that could exist independently.

Why do we use it? We use <article> for content such as blog posts, news articles, forum posts, reviews, or other independent content.

Easy way to remember: Article = One independent piece of content

Example:

<article>
    <h2>What is HTML?</h2>
    <p>HTML creates the structure of webpages.</p>
</article>

Multiple articles:

Article 1: HTML

HTML is used to create the structure of webpages.

Article 2: CSS

CSS is used to style webpages.

<aside>

Definition: The <aside> element represents content that is related to the main content but is not part of the primary information.

Why do we use it? We use <aside> for additional information such as related links, tips, author information, or a sidebar.

Easy way to remember: Aside = Extra / Related information

Example:

<aside>
    <h3>Did You Know?</h3>
    <p>HTML is a markup language.</p>
</aside>

💡 Quick Tip

<aside> does not necessarily have to appear visually on the side. CSS controls its visual position.

<footer>

Definition: The <footer> element represents the ending information of a webpage or section.

Why do we use it? We use <footer> for information such as copyright, contact information, author details, or useful links.

Easy way to remember: Footer = Ending / Bottom information

Example:

<footer>
    <p>© 2026 Fida Hussain</p>
</footer>
